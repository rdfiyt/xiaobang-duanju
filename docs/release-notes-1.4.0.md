## 小邦短剧 1.4.0

加一个豆包账号，就能免费做短剧、免费生图、免费出视频。

### 这一版改了什么

- **新增画风预设「3D 真人」** —— 3D 半写实 CG 角色 / 场景 / 道具，和原有的二维动漫、3D 国漫、AI 真人并列。在画风下拉框里直接选。
- **失败上报带现场** —— 任务失败时自动附上截图、运行流水、日志尾部、环境快照，提给客服时不用再一句句描述。
- **40 条创作提示词模板改由服务端下发** —— 以后调文案不用等发版。
- 后台流水时间戳不再差 8 小时。
- 视频取片、额度用完反复横跳等 1.3.9 遗留问题继续修。

### 装哪个包

| 你的电脑 | 下载 |
| --- | --- |
| Windows 10 / 11（64 位） | `小邦短剧-1.4.0-setup.exe` |
| macOS · Apple 芯片（M1 / M2 / M3 / M4） | `小邦短剧-1.4.0-arm64.dmg` |
| macOS · Intel 芯片 | `小邦短剧-1.4.0.dmg` |

不知道自己是哪种 Mac：左上角苹果菜单 →「关于本机」，「芯片」那一行写着 Apple M 开头的就选 arm64，写着 Intel 的就选另一个。

### 第一次打开会弹什么

**macOS**：提示「无法验证开发者」或「无法打开，因为 Apple 无法验证」。

这不是安装包坏了。到「系统设置 → 隐私与安全性」，页面下方找到小邦短剧那一行，点「仍要打开」；或者在 Finder 里右键图标 →「打开」→ 再点「打开」。

> 如果提示的是「已损坏，无法打开」——那才是真的有问题，请把包名和提示原文发给我们。

**Windows**：SmartScreen 会拦一次，点「更多信息」→「仍要运行」。安装包未做数字签名，这一步是正常的。

```
b5e516efb2e4730b2d1c7444973652d29d9c7f8434638521e982a02605b1a840  小邦短剧-1.4.0-arm64.dmg
fdf59b6c6b42757d7ffd37290d119ba2d0b047414809db1635a4dd9e6d744b6e  小邦短剧-1.4.0.dmg
df4f301e6eb75a7c015adbf9af3e9416c53fe5b97afda0592fda081c14ecfb30  小邦短剧-1.4.0-setup.exe
```

macOS / Linux 在终端跑 `shasum -a 256 文件名`，Windows 用 PowerShell 的 `Get-FileHash -Algorithm SHA256 文件名`，和上面一致就是完整的。

### 从 1.3.9 升级

直接装新包覆盖即可，作品、素材、设置都在用户数据目录里，不会被覆盖。

Windows 用户如果收到「热更新」提示，点「立即更新」只下 1 MB 多，不用重新装整个包。
